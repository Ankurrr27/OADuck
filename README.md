# OA Duck — Practice with Purpose

**OA Duck** is a focused online assessment and coding practice workspace engineered to simulate real-world technical online assessments (OAs) while helping candidates build discipline, problem-solving skills, and interview readiness.

---

##  What OA Duck Does ?

OA Duck bridges the gap between casual coding practice and high-stakes company online assessments. It provides a structured environment where candidates can practice algorithms, take realistic timed tests under monitored conditions, and receive instant feedback on their solutions.

---

## 🌟 Key Features

### 1. Curated Question Library
- **Comprehensive Problem Catalog:** Access a diverse collection of coding problems categorized by difficulty (*Easy*, *Medium*, *Hard*) and topic tags.
- **Progress Tracking:** Easily track which questions have been attempted, solved, or remain pending.
- **Flexible Search & Filtering:** Filter problems by topic, difficulty level, submission status, or attempt frequency.

---

### 2. 🛡️ Realistic Assessment Environment (OA Mode)
- **Monitored Testing Sessions:** Simulates the strict conditions of real company Online Assessments.
- **Anti-Distraction & Integrity Rules:** Built-in detection for copy-paste actions, tab switches, and unauthorized browser navigation during assessments.
- **Verified Full-Screen Mode:** Requires full-screen commitment for official assessment runs.
- **Timed Workspaces:** Configurable countdown timers with toggles for elapsed vs. remaining session time.
- **Session Locking:** Automatically locks completed or terminated assessments to preserve official results.

---

### 3. 💻 Interactive Code Editor & Test Execution
- **Professional Code Editor:** Fully feature-rich editor supporting C++ with syntax highlighting and code completion.
- **Sample Testing:** Test code against public sample cases before final submission.
- **Comprehensive Judge Verification:** Evaluate submissions against comprehensive hidden test suites for final verdicts (Passed, Wrong Answer, Time Limit Exceeded, Runtime Error, Compile Error).
- **Performance Metrics:** View exact runtime execution speed (ms) and memory usage (MB) for each submission.

---

### 4. 🦆 Duck Insight (AI Assessment Tutor)
- **Post-Assessment AI Review:** On-demand analysis for incorrect assessment submissions.
- **Optimal Reference Solution:** View reference solutions and algorithmic breakdowns.
- **Step-by-Step Walkthroughs:** Clear text explanations of optimal algorithms and how test cases exercise them.
- **Complexity Analysis:** Deep-dive into optimal Time and Space complexity ($O(N)$, $O(1)$, etc.).
- **Concrete Mistake & Bug Analysis:** Pinpoint exact logic flaws, edge-case omissions, or compiler/runtime errors in submitted code.

---

### 5. 📊 Stats & User Performance Dashboard
- **Personal Profile & Stats:** Track overall accuracy rates, total problems solved, total attempts, and topic mastery over time.
- **Submission History:** Review historic assessment attempts, session outcomes, and violation logs.
- **Customization:** Manage personal account details, profile picture, and security settings.

---

### 6. ⚙️ Admin Management Suite
- **Question Creation & Editing:** Add new problems with custom descriptions, constraints, hints, and sample/hidden test cases.
- **Optimal Solution Repository:** Store and manage reference solutions for every problem.
- **User & Content Administration:** Oversee registered users, assign roles, and manage the problem library.
